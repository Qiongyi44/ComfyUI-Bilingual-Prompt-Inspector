ComfyUI 双语提示词检查器 v19 混合提示词边界增强版
=================================================

一、安装

1. 关闭 ComfyUI。
2. 解压“ComfyUI-Bilingual-Prompt-Inspector-v19-public.zip”。
3. 将解压得到的 ComfyUI-Bilingual-Prompt-Inspector 文件夹复制到：
   ComfyUI\custom_nodes\
4. 启动 ComfyUI。
5. 浏览器按 Ctrl+F5 强制刷新。
6. 在节点菜单中依次选择：
   文本 → 提示词工具 → 双语提示词检查器（英文输出）
7. 节点最底部的“关于作者”不会影响工作流；点击后可选择“访问作者社区主页”，由默认浏览器打开。

二、首次使用

1. 在顶部英文区域输入提示词。
2. 点击“完成编辑”，查看英文标签、绿色中文解释和底部明细。
3. 把节点右侧“英文提示词”连接到模型对应的文本编码节点。
4. 中文解释不会进入模型，只有英文实际输出会传递给工作流。
5. 在标签联动模式中双击英文或中文标签，可以设置或清除该标签的权重。

三、翻译助手

纯词库模式不需要 API。复杂文本可在“助手设置”中选择 Ollama 或 OpenAI 兼容 API。
API Key 不包含在分享包中。首次安装、完整卸载后重新安装、更换服务商或更换 API 地址时，都需要重新配置 Key。

四、大型词库

公开扩展包不包含大型 Danbooru 数据库。它是可选组件，不安装也不影响节点基本功能。
如需使用，推荐自行下载 ffdkj 仓库的 tag.sqlite，再使用扩展工具转换。不要直接改名覆盖。
完整下载、转换、更新及回退方法见压缩包外的“大型词库手动安装说明.txt”。

五、升级与重装

直接覆盖原目录属于升级，通常保留当前安装配置。
先删除整个扩展目录再安装属于重新安装，旧 API 配置会失效。
卸载前如需保留个人词库，请先在词库管理器中导出。

六、安全提醒

不要把没有登录保护的 ComfyUI 直接开放到公网。
使用外部 API 时，提示词和规则会发送到用户自己选择的服务商。
详细功能、操作方法和故障排查请阅读扩展文件夹中的 README.md。
