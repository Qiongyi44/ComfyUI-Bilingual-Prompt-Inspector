ComfyUI 双语提示词检查器 v1.1.0 更新与升级说明
================================================

一、自 v1.0.0 发布后的主要更新
-----------------------------

1. 词库搜索支持中文、英文、别名和概念模糊匹配；例如搜索“丝袜”可找到连裤袜、长筒袜、过膝袜等相关标签。
2. 搜索结果每次显示 40 项，可继续“搜索更多”；追加结果时保留当前滚动位置，全部显示后明确提示没有更多结果。
3. 未收录标签可直接搜索候选或手动加入个人词库，不再只提示购买或配置外部 API。
4. 助手设置新增 LM Studio 本地预设，并修复 OpenAI 兼容地址的 /v1/chat/completions 拼接。
5. 中文／混合文本编辑区支持拖动高度、保存高度和展开编辑。
6. Anima 官方顺序整理细化为质量、人数、角色、作品、画师、外观服装、动作姿势、镜头构图、画风、场景环境等分类；中文联动区用分类表格显示，分类名不会写入实际提示词。
7. 英文实际输出新增“清空 → 确认清空 → 撤销”，同时支持 Ctrl+Z；中文草稿不设置重复清空入口。
8. 适配 ComfyUI 0.35.1／0.36.0：顶部原始英文文本框保持可见，传统节点和现代节点均可使用；修复标签管理展开／收起后的大块空白。
9. 发布包改为升级安全结构，不再携带空个人词库和默认运行设置，避免覆盖旧用户数据。

二、从旧版覆盖升级
------------------

1. 关闭 ComfyUI。
2. 建议先在词库管理器导出一次个人词库，作为额外备份。
3. 不要删除旧的 ComfyUI-Bilingual-Prompt-Inspector 文件夹。
4. 把新版同名文件夹复制到 ComfyUI\custom_nodes，选择合并目录并替换同名程序文件。
5. 不要使用会先清空目标目录的镜像同步工具，也不要先删旧目录再解压。
6. 启动 ComfyUI，浏览器按 Ctrl+F5 强制刷新。

三、正常覆盖升级会保留什么
--------------------------

- data\user_tags.json：个人词库。
- data\packs\community_*.json：用户导入的社区词库。
- data\pack_settings.json：词库包启停选择。
- data\danbooru_tags.sqlite3 和 data\large_dictionary.json：本地大型词库及开关。
- data\backups、data\runtime、data\user_config：备份、安装身份和兼容配置。
- ComfyUI 用户目录中的助手设置与 API Key。
- 同一浏览器、同一 ComfyUI 域名和端口下的收藏与最近使用记录。

收藏和最近使用属于浏览器本地存储。更换浏览器配置、访问域名或端口后，浏览器会使用另一份本地存储；这不是扩展覆盖升级造成的数据丢失。

四、重新安装与卸载注意事项
--------------------------

先删除旧扩展目录再安装属于“重新安装”，不是覆盖升级。这样会删除扩展目录中的个人词库、社区词库、本地大型数据库和备份。完整卸载或重装前务必先导出个人词库，并自行备份需要保留的数据库和配置。

公开分享包不包含个人 API Key、服务商配置、个人词库、运行数据或第三方大型词库数据库。
